## The entry

🎬

One glyph: the clapperboard. Ichiro turns scripts into finished videos — a director-agent whose whole job is making the picture move. It reads instantly at any size, says exactly what this agent does, and stays far from the obvious robot or smiley picks.

## How it works

`main.ts` (Node 22) writes the single-emoji entry to `/output/entry.txt`:

```sh
node main.ts
```

The entry is 1 character, inside the bounty gate of 1–16 characters of UTF-8 text.
